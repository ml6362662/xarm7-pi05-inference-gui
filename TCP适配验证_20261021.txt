TCP Pose 模型适配验证 2026-10-21

已支持
pi05_xarm7_tcp_state：实测绝对 TCP 状态 → 绝对 TCP 目标 → 逆运动学 → 关节伺服。
模型坐标格式：基座 XYZ 米、四元数 wxyz、夹爪开度比例。
与训练一致地处理四元数单位化和时间连续符号；SDK 边界转换为毫米与 RPY 弧度。
自动识别原关节模型和 TCP 模型，不额外增加界面参数。
UI 按模型显示关节角或末端位置／姿态；记录保存模型定义、逆解及下发指令。

验证
150 项模拟设备与离线测试通过，包括模式切换、单位、四元数、坐标系不匹配、逆解错误、暂停取消、状态输入和界面显示。
三个 TCP 检查点（30000、21000、12000 步）均严格加载并在 3 个录制画面上完成 GPU 推理；输出 50×8、数值有限、转换正常。
原绝对关节模型通过相同 3 个录制画面的 GPU 兼容检查。
桌面程序 --load-smoke 成功加载 TCP 模型、正确显示模式，hardware_connected=false。
依据：tcp_inference_check.json、joint_compatibility_check.json、gui_load_check.json、tcp_adapter_validation.json。

使用
重新打开原有「启动π0.5推理」图标，选择 TCP 模型并加载；界面应显示「绝对末端 Pose」。
三个 TCP 模型和原关节模型均已列入模型下拉框。
权重、训练配置、归一化文件及 training_snapshot/dataset_spec.json 保持配套。
开始前只核对设备／工具坐标，不自动修改设备参数。

范围
本次没有连接机械臂、发送运动或夹爪指令；实机动作与任务成功率尚未验证。
仍沿用现有速度、夹爪等待和开合时序；未引入抓取成功检测。
相对 pose、其他四元数顺序或坐标定义不在本次支持范围内。
